# Sistema de Autenticación - FastAPI & PostgreSQL

Backend API desarrollado en **FastAPI** para la gestión segura de usuarios, autenticación mediante JWT, asignación de roles (`cliente`, `admin`) y conexión a base de datos **PostgreSQL**.

## 🛠️ Tecnologías

- Python 3.x / FastAPI
- PostgreSQL (Supabase)
- PyJWT & Passlib (Bcrypt)

## 🚀 Inicio Rápido

1. Instalar dependencias: `pip install -r requirements.txt`
2. Configurar el archivo `.env` con las credenciales de la base de datos.
3. Ejecutar el servidor: `uvicorn main:app --reload`
